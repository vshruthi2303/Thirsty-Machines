# Thirsty Machines

Static site. No build step.

Files: `index.html` (the map), `add-up-to.html`, `about.html`, `support.js`.

## Deploy

1. Create a new GitHub repo and push the contents of this folder to the repo root.
2. On Vercel: **Add New → Project → Import** the repo.
3. Framework Preset: **Other**. Leave Build Command empty. Output Directory: `./`
4. Deploy.

Any push to `main` redeploys automatically.
